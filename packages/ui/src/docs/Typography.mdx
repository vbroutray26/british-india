# Typography (D-17)

| Role | English | ଓଡ଼ିଆ | हिन्दी |
|---|---|---|---|
| Display (titles, headings) | **Gloock** | Noto Serif Oriya | Rozha One |
| Interface and body | **Urbanist** | Anek Odia | Anek Devanagari |
| Archival voice (passages) | **Newsreader** (true italic) | Noto Serif Oriya | Rozha One *(text serif to choose in M7)* |
| Data, IDs | system monospace | — | — |

Each language has its **own font stack** listing only its script, so shared characters (the danda ।, ZWJ) never pull in another script's font.
Measured font weight per page: English ≈ 130 KB, Odia ≈ 230 KB, Hindi ≈ 293 KB.

**Rules:** no synthetic italic or bold; Odia and Hindi emphasis is upright (weight or colour); no upper-casing or letter-spacing in Indic scripts;
line height 1.55 (Latin), 1.7 (Devanagari), 1.75 (Odia); reading measure 680 px (Latin), 620 px (Indic).
