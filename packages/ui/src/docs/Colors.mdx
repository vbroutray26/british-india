export const pick = (o) => Object.fromEntries(Object.entries(o).filter(([k]) => !k.startsWith('$')));
export const sem = (mode, pal) => Object.fromEntries(Object.entries(tokens.semantic[mode]).map(([k, ref]) => [k, tokens.color[pal][ref.split('.')[1]]]));

# Colour

Two modes, each with a light and dark scheme. **Components use the semantic names** (`--color-text`, `--color-link`, `--viz-1` …); modes remap them.
Every text pairing is tested at ≥ 4.5:1 and every chart colour at ≥ 3:1 in all four schemes.

## Data visualisation
Eight categorical colours per scheme, chosen by `scripts/pick-viz.mjs`: ≥ 3:1 on the background, clearly different with normal vision,
and the first six still distinct under protanopia, deuteranopia and tritanopia. Always pair colour with shape or labels.
